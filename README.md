## ✨ Identitas Visual & Fitur (Corporate Highlights)

Portal ini tidak hanya menampilkan informasi statis, tetapi dirancang sebagai wajah digital perusahaan yang interaktif dan responsif di berbagai perangkat.

*   **Premium Brand Presentation:** Tata letak antarmuka yang dirancang untuk menonjolkan profesionalisme, visi-misi, dan rekam jejak perusahaan logistik.
*   **Service & Fleet Showcase:** Katalog layanan pengiriman dan etalase armada logistik yang disajikan dengan animasi transisi yang mulus.
*   **Responsive & Mobile-First:** Tampilan yang beradaptasi sempurna dari layar monitor resolusi tinggi hingga perangkat seluler terkecil klien.
*   **Optimized Assets:** Pengelolaan gambar dan aset visual yang dikompresi agar *website* memuat dengan instan tanpa mengurangi kualitas.

## 🚀 Panduan Instalasi (Development Setup)

Untuk menjalankan portal ini di *environment* lokal:

```bash
# 1. Clone repositori
git clone [https://github.com/UlulAzmiALatala/logistic-compro-new.git](https://github.com/UlulAzmiALatala/logistic-compro-new.git)
cd logistic-compro-new

# 2. Install dependensi Node.js
npm install

# 3. Jalankan server development Vite
npm run dev

# 4. Build untuk tahap Production
npm run build
```
